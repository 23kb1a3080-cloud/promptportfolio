# 🚀 Quick Start Guide

Get your portfolio running in under 5 minutes!

## Step 1: Open the Portfolio

Simply double-click `index.html` to open it in your default web browser.

**Or** use a local server (recommended for better experience):

### Using Python (Windows/Mac/Linux)
```bash
# Python 3
python -m http.server 8000

# Then visit: http://localhost:8000
```

### Using Node.js
```bash
# Install http-server (one-time)
npm install -g http-server

# Run from portfolio folder
http-server

# Then visit: http://localhost:8080
```

### Using VS Code Live Server
1. Install "Live Server" extension
2. Right-click `index.html`
3. Select "Open with Live Server"

---

## Step 2: Essential Updates (5 minutes)

Open `index.html` with a text editor (VS Code, Notepad, etc.) and update:

### Find & Replace (Ctrl+H in most editors)

1. **Email**: Replace `contact@example.com` with your email
2. **Phone**: Replace `+91 XXXX XXXX XX` with your phone
3. **GitHub**: Replace `https://github.com` with your profile
4. **LinkedIn**: Replace `https://linkedin.com` with your profile

**That's it!** Your portfolio is now personalized with your contact info.

## Step 5: Deploy (Free Options)

### GitHub Pages (Free, Recommended)
1. Create GitHub account (github.com)
2. Create repository named: `yourusername.github.io`
3. Upload portfolio files (index.html, styles.css, script.js)
4. Wait 1-2 minutes
5. Visit `https://yourusername.github.io` ✨

### Netlify (Free, Easiest)
1. Go to netlify.com
2. Click "Add new site"
3. Drag & drop your portfolio folder
4. Done! Get a live URL instantly

### Vercel (Free)
1. Go to vercel.com
2. Upload your portfolio folder
3. Auto-deployed, get live URL

## 🆘 Troubleshooting

### Website doesn't load
- Make sure all 3 files (html, css, js) are in same folder
- Try opening in different browser
- Clear browser cache (Ctrl+Shift+Del)

### Styles look broken
- Refresh page (Ctrl+F5)
- Check that `styles.css` and `script.js` are in same folder
- Check file names are exactly correct (case-sensitive)

### Links don't work
- Check that URLs start with `https://`
- Test links in browser to ensure they're correct
- Update GitHub/LinkedIn URLs with your actual profiles
